# 🚀 Project Overview

The SAM Attendance Management System is a modern web-based application designed to simplify and digitize the process of managing student attendance in classrooms.

This project was developed to replace traditional manual attendance systems with a smarter, faster, and more interactive digital solution.

The system allows teachers to:

✅ Securely Login  
✅ Manage Students  
✅ Mark Attendance Daily  
✅ Track Attendance Records  
✅ Monitor Present/Absent Statistics  
✅ Generate Attendance Insights  

The platform is built using a modern full-stack architecture combining:

- Python Flask
- MySQL
- HTML
- CSS
- JavaScript

with a premium glassmorphism-inspired user interface.
